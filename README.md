# Spark - Atividade Prática

<p>O projeto tem como finalidade apresentar uma breve script em Python feito para resolver uma situação problema de processamento de dados em uma determinada empresa. Acompanhe abaixo o contexto e a página de apresentação do projeto:
</p>

<h2>Contexto - Situação Problema</h2>
<p>o departamento de TI de uma grande plataforma de e-commerce (TechStore). Todos os dias, o sistema registra milhões de transações de vendas contendo dados de produtos, categorias, valores, clientes e localizações. 
Problema: A equipe de inteligência de negócios precisa gerar um relatório diário que identifique a quantidade de vendas de produtos de alto valor (preço maior que R$ 500,00) agrupados por categoria.</p>

<p>Inicialmente, a equipe tentou utilizar scripts simples em Python com bibliotecas tradicionais baseadas em nó único (como o Pandas). No entanto, à medida que a base de dados cresceu para gigabytes e petabytes: 
 O servidor central começou a apresentar erros de estouro de memória (OutOfMemoryError).
 O processamento levou horas para ser concluído, pois utilizava apenas um núcleo da CPU por vez. 
</p>

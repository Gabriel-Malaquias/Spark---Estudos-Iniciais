Arquitetura & Execução no Apache Spark

Análise de fluxo: Carga de Dados RDD, Transformações Lazy e Disparo de Ação

🐍 Script de Processamento (PySpark) Batch Driver 
from pyspark.sql import SparkSession

# 1. Inicializa a sessão local do Spark
spark = SparkSession.builder \
    .appName("DemonstracaoSpark") \
    .master("local[*]") \
    .getOrCreate()

# 2. Dados de exemplo
dados = [
    ("Notebook", "Eletrônicos", 3500),
    ("Celular", "Eletrônicos", 2000),
    ("Cadeira", "Móveis", 450),
    ("Mesa", "Móveis", 800),
    ("Monitor", "Eletrônicos", 1200)
]

# 3. Cria o DataFrame distribuído
df = spark.createDataFrame(dados, ["Produto", "Categoria", "Preco"])

# 4. TRANSFORMAÇÕES (Lazy Evaluation)
df_filtrado = df.filter(df["Preco"] > 500)
df_resultado = df_filtrado.groupBy("Categoria").count()

# 5. AÇÃO: Dispara processamento e exibe
df_resultado.show()

# 6. Encerra a sessão
spark.stop()
⚙️ Plano de Execução Lógico (DAG) Grafo Acíclico
1. createDataFrame Input
Distribui a coleção Python para nós trabalhadores como RDD particionado.
2. filter(Preco > 500) Transformação (Lazy)
Não lê os dados de imediato. Apenas adiciona uma regra de projeção/filtro ao plano lógico.
3. groupBy("Categoria").count() Transformação (Shuffle)
Planeja a redistribuição e agrupamento dos dados entre partições do cluster.
4. show() Ação (Disparo)
Quebra a preguiça (Lazy). O Catalyst Optimizer gera o plano físico e dispara tarefas aos nós executores.
